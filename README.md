# MeterPatrol
เว็บแอปภาษาไทยสำหรับสำรวจมิเตอร์และอุปกรณ์ประกอบหน้างาน

## เริ่มใช้งาน
ใช้ Python 3.12 ขึ้นไป ไม่มีแพ็กเกจเพิ่มเติม

```sh
cd /workspace/MeterPatrol
python app.py
```

เปิดพอร์ต 8000 ผ่านช่องทางเข้าถึงเว็บของเครื่องที่รันแอป ค่าเริ่มต้นรับการเชื่อมต่อเฉพาะเครื่องเดียวกัน หากใช้เครือข่ายภายในที่เชื่อถือได้ ตั้ง `HOST=0.0.0.0` ได้ ใช้ `PORT` เปลี่ยนพอร์ต และ `METERPATROL_DB` เปลี่ยนตำแหน่งฐานข้อมูล

## ความสามารถ
- บันทึกวันที่ ผู้สำรวจ สถานที่ เลขประจำมิเตอร์ ประเภท เลขอ่าน และหมายเหตุ
- เพิ่มรายการอุปกรณ์พร้อมจำนวนชำรุดและจำนวนใหม่
- ค้นหาประวัติ และรายงานเฉพาะรายการหรือรายการทั้งหมดที่ตรงกับการค้นหา
- พิมพ์เอกสารหรือบันทึก PDF ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์
- เก็บข้อมูลถาวรใน SQLite (`data/surveys.sqlite3`) สำรองไฟล์นี้เมื่อหยุดแอป

รุ่นเริ่มต้นนี้ยังไม่มีระบบเข้าสู่ระบบ แก้ไข/ลบข้อมูล แนบรูป หรือส่งออก Word ใช้ในเครื่องหรือเครือข่ายที่เชื่อถือได้ก่อนนำขึ้นอินเทอร์เน็ตสาธารณะ การพิมพ์ PDF ใช้ความสามารถของเบราว์เซอร์
