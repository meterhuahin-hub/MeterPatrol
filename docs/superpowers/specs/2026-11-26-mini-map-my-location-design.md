# จุดตำแหน่งฉันในมินิแผนที่

## เป้าหมาย
ให้คนสำรวจเห็นตำแหน่งตัวเองแบบจุดสีฟ้าที่ขยับตามตัวเหมือน Google Maps บนมินิแผนที่ของชุดปี WBS TR ที่เปิดอยู่ แล้วรู้ทันทีว่าอยู่ห่างหม้อแปลงและเสาที่ใกล้ที่สุดกี่เมตร

## แนวทางที่พิจารณา
- **ก. เมนู "ใกล้ฉัน" แยก:** เห็นงานทุก TR และหา TR ที่ใกล้ที่สุดเองได้ แต่ผู้ใช้ไม่ได้เลือก
- **ข. จุดตำแหน่งฉันในมินิแผนที่เดิม:** ผู้ใช้เลือกแบบนี้ ใช้งานเมื่อเลือกปี WBS และ TR แล้ว

## สิ่งที่จะทำ
- เพิ่มปุ่ม "◎ ตำแหน่งฉัน" ในแถบเครื่องมือมินิแผนที่ ถ้ากำลังดูแผนผังแนวสาย ระบบจะสลับไปแผนที่ถนนจริงให้ เพราะตำแหน่ง GPS ใช้ได้กับแผนที่จริงเท่านั้น
- ติดตามตำแหน่งต่อเนื่อง แสดงจุดสีฟ้าและวงจางตามความคลาดเคลื่อนของ GPS
- ครั้งแรกซูมไปที่ตัวเรา (ระดับถนน) หลังจากนั้นจุดจะขยับเอง ถ้าผู้ใช้เลื่อนแผนที่ไปดูที่อื่น แผนที่จะไม่ดึงกลับ กดปุ่มอีกครั้งเพื่อกลับมาที่ตัวเรา
- แถบสถานะบอก: ห่างหม้อแปลงของชุดนี้กี่เมตร, เสาที่ใกล้ที่สุดคือเสาไหน ห่างกี่เมตร และความคลาดเคลื่อน GPS
- ถ้าหม้อแปลงยังไม่มีพิกัดบนแผนที่ บอกว่ายังไม่มีพิกัดหม้อแปลง และยังแสดงเสาที่ใกล้ที่สุด
- หยุดติดตามเมื่อปิดมินิแผนที่ สลับเป็นแผนผังแนวสาย หรือกดปิดปุ่ม
- ไม่อนุญาตตำแหน่งหรืออุปกรณ์ไม่รองรับ: แสดงข้อความ ไม่บล็อกการใช้งานอื่น

## สิ่งที่ไม่ทำ
- ไม่บันทึกตำแหน่งของผู้ใช้ลงชีตหรือส่งไปเซิร์ฟเวอร์
- ไม่เปลี่ยนพิกัดเสาหรือหม้อแปลง
- ไม่แสดงงานของ TR อื่น

## ข้อจำกัด
- แก้เฉพาะ `Index.html` ไม่ต้องแก้ `Code.gs`
- ระยะทางคำนวณแบบเส้นตรง ไม่ใช่ระยะตามถนน
