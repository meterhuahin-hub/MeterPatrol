# มิเตอร์ Patrol หลายเครื่องในเสาเดียวกัน

หน้า Patrol เลือกเครื่องที่ 1–8 ได้โดยไม่ต้องเรียงหมายเลข แต่ละเครื่องยังเป็นคนละงาน มี PEA รูปถ่าย พัสดุ การส่งมอบ และการตรวจรับของตัวเอง

หลังบันทึก กด “เพิ่มมิเตอร์ที่เสาเดียวกัน” เพื่อใช้พิกัด ขนาดเสา ที่อยู่ งาน Patrol กฟฟ. และวันที่สำรวจเดิม ข้อมูลเฉพาะมิเตอร์ ชื่อผู้ใช้ไฟ CA ขนาด/เฟส ประเภทงาน หมายเหตุ รูปถ่าย และพัสดุจะล้างสำหรับเครื่องใหม่ ระบบแนะนำหมายเลขที่ว่างถัดจากเครื่องที่เพิ่งบันทึก และเปลี่ยนไปหมายเลขว่างอื่นได้ทันที

ปุ่มเครื่องที่มีข้อมูลแล้วแสดง ✓ การเลือกซ้ำจะขอให้เปิดแก้ไขงานเดิม ไม่สร้างงานใหม่ การกด “เริ่มเสาต้นใหม่” หรือล้างแบบฟอร์มยกเลิกกลุ่มปัจจุบัน หากมีข้อมูลที่ยังไม่ได้บันทึก ระบบขอยืนยันก่อนใช้คำสั่งเริ่มเสาต้นใหม่หรือเพิ่มมิเตอร์

## การเก็บข้อมูล

- DATA ยังคง 58 คอลัมน์เดิม
- เพิ่มชีต `PatrolPoleGroups` อัตโนมัติเมื่อเริ่มใช้กลุ่มเสา มีคอลัมน์ Record ID, กลุ่มเสา Patrol, ผู้บันทึก, บันทึกเมื่อ
- `listPatrol` ส่ง `patrolPoleGroup` ประกอบแต่ละงาน ใช้รหัสกลุ่มที่ระบุชัดเจน ไม่เดาจากพิกัด พิกัดเหมือนกันแต่คนละกลุ่มยังเป็นคนละเสา การแก้พิกัดของงานไม่เปลี่ยนกลุ่ม
- API ป้องกันหมายเลขเครื่องซ้ำในกลุ่มภายใต้ Script Lock ก่อนสร้างรูป การส่งคำขอซ้ำของงานเดิมยังใช้ Request ID และ fingerprint เดิม
- การแก้ไขรักษารหัสกลุ่มเดิม และห้ามเปลี่ยนเป็นหมายเลขที่ถูกใช้แล้ว การลบงานลบสมาชิกกลุ่มด้วย ทำให้ใช้หมายเลขนั้นใหม่ได้
- งานเก่ายังไม่มีรหัสกลุ่ม ให้เปิดแก้ไข เลือกหมายเลขเครื่องและบันทึกก่อน แล้วกดเพิ่มมิเตอร์ที่เสาเดียวกัน ระบบจึงสร้างกลุ่มให้รายการเดิม โดยไม่จับรวมงานเก่าทั้งหมดตามพิกัด

## การแสดงผล

ประวัติ รายงานบนเว็บ/Excel/PDF และรายการงานผู้รับจ้าง/ช่างผู้ควบคุมงานจัดสมาชิกของกลุ่มให้อยู่ติดกัน และเรียงหมายเลขเครื่องภายในกลุ่ม เช่น 1, 2, 5 ไม่เติมเลขเครื่องที่ไม่มีข้อมูล งานที่ไม่มีกลุ่มยังคงลำดับเดิม

กดหมุดของมิเตอร์ใดแล้ว ส่วนบนของรายละเอียดแสดงรายการมิเตอร์กลุ่มเดียวกัน พร้อมหมายเลขเครื่อง PEA ขนาด/เฟส และสถานะ เน้นรายการที่เลือก และกดเปลี่ยนเครื่องได้ รายการผู้รับจ้างไม่แสดงสมาชิก U_CUBE ผมต. ที่ไม่มีสิทธิ์เห็น กลุ่มหมุดตามพิกัดของ Leaflet ยังคงทำหน้าที่ขยายหมุดที่ซ้อนกัน ซึ่งแยกจากรหัสกลุ่มเสาจริง

## การตรวจสอบ

`test-inspector.cjs` ตรวจการเก็บกลุ่ม การข้ามหมายเลข การป้องกันซ้ำ การส่งคำขอซ้ำ การแก้ไข การผูกงานเก่า สิทธิ์ และการลบ ด้วย Google APIs จำลอง

`check-patrol-pole-groups.cjs` ตรวจใน Chromium ขนาดจอมือถือ: บันทึก 2 → 5 → 1 ใช้กลุ่มเดียวกัน คงข้อมูลเสา ล้างข้อมูลมิเตอร์/รูป/พัสดุ เปิดงานเดิมเมื่อเลือกเครื่องซ้ำ เรียงประวัติและรายงาน และเลือกงานจากหมุดในทั้งสองหน้า

นำ Code.gs และ Index.html ไปแทนใน Apps Script แล้ว Deploy เวอร์ชันใหม่หนึ่งครั้ง ไม่ต้องสร้างชีตหรือแทรกคอลัมน์ด้วยตัวเอง
