# มิเตอร์ Patrol หลายเครื่องในเสาเดียวกัน

หน้า Patrol เลือกเครื่องที่ 1–8 ได้โดยไม่ต้องเรียงหมายเลข แต่ละเครื่องยังเป็นคนละงาน มี PEA รูปถ่าย พัสดุ การส่งมอบ และการตรวจรับของตัวเอง

หลังบันทึก กด “เพิ่มมิเตอร์ที่เสาเดียวกัน” เพื่อใช้พิกัด ขนาดเสา ที่อยู่ งาน Patrol กฟฟ. และวันที่สำรวจเดิม ข้อมูลเฉพาะมิเตอร์ ชื่อผู้ใช้ไฟ CA ขนาด/เฟส ประเภทงาน หมายเหตุ รูปถ่าย และพัสดุจะล้างสำหรับเครื่องใหม่ ระบบแนะนำหมายเลขที่ว่างถัดจากเครื่องที่เพิ่งบันทึก และเปลี่ยนไปหมายเลขว่างอื่นได้ทันที

ปุ่มเครื่องที่มีข้อมูลแล้วแสดง ✓ การเลือกซ้ำจะขอให้เปิดแก้ไขงานเดิม ไม่สร้างงานใหม่ การกด “เริ่มเสาต้นใหม่” หรือล้างแบบฟอร์มยกเลิกกลุ่มปัจจุบัน หากมีข้อมูลที่ยังไม่ได้บันทึก ระบบขอยืนยันก่อนใช้คำสั่งเริ่มเสาต้นใหม่หรือเพิ่มมิเตอร์

## การเก็บข้อมูล

- DATA ยังคง 58 คอลัมน์เดิม
- เพิ่มชีต `PatrolPoleGroups` อัตโนมัติเมื่อเริ่มใช้กลุ่มเสา มีคอลัมน์ Record ID, กลุ่มเสา Patrol, ผู้บันทึก, บันทึกเมื่อ
- `listPatrol` ส่ง `patrolPoleGroup` ประกอบแต่ละงาน ใช้รหัสกลุ่มที่ระบุชัดเจน ไม่เดาจากพิกัด พิกัดเหมือนกันแต่คนละกลุ่มยังเป็นคนละเสา การแก้พิกัดของงานไม่เปลี่ยนกลุ่ม
- API ป้องกันหมายเลขเครื่องซ้ำในกลุ่มภายใต้ Script Lock ก่อนสร้างรูป การส่งคำขอซ้ำของงานเดิมยังใช้ Request ID และ fingerprint เดิม
- การแก้ไขงานทั่วไปยังรักษารหัสกลุ่มเดิม และห้ามเปลี่ยนเป็นหมายเลขที่ถูกใช้แล้ว การลบงานลบสมาชิกกลุ่มด้วย ทำให้ใช้หมายเลขนั้นใหม่ได้
- งานเก่ายังไม่มีรหัสกลุ่ม ให้เปิดแก้ไข เลือกหมายเลขเครื่องและบันทึกก่อน แล้วกดเพิ่มมิเตอร์ที่เสาเดียวกัน ระบบจึงสร้างกลุ่มให้รายการเดิม โดยไม่จับรวมงานเก่าทั้งหมดตามพิกัด

## การแสดงผล

ประวัติ รายงานบนเว็บ/Excel/PDF และรายการงานผู้รับจ้าง/ช่างผู้ควบคุมงานจัดสมาชิกของกลุ่มให้อยู่ติดกัน และเรียงหมายเลขเครื่องภายในกลุ่ม เช่น 1, 2, 5 ไม่เติมเลขเครื่องที่ไม่มีข้อมูล งานที่ไม่มีกลุ่มยังคงลำดับเดิม

กดหมุดของมิเตอร์ใดแล้ว ส่วนบนของรายละเอียดแสดงรายการมิเตอร์กลุ่มเดียวกัน พร้อมหมายเลขเครื่อง PEA ขนาด/เฟส และสถานะ เน้นรายการที่เลือก และกดเปลี่ยนเครื่องได้ รายการผู้รับจ้างไม่แสดงสมาชิก U_CUBE ผมต. ที่ไม่มีสิทธิ์เห็น สองหน้างานรวมหมุดเฉพาะรหัสกลุ่มเสาเดียวกัน ไม่รวมตามพิกัด ระยะใกล้ หรือระดับซูม งานที่ยังไม่ผูกเสาเป็นหมุดเดี่ยว แม้พิกัดตรงกัน หมุดลงตรง LatLong จริงของงาน แม้พิกัดตรงกันก็ไม่เลื่อนหมุดหรือสร้างเส้นชี้ตำแหน่ง ไม่เปลี่ยน DATA หรือลิงก์นำทาง หน้าประวัติยังใช้การรวมหมุดตามระยะตามเดิม

เมื่อกดกลุ่มหมุดในหน้าผู้รับจ้างหรือช่างผู้ควบคุมงาน จะเปิดรายละเอียดเครื่องแรกพร้อมรายการมิเตอร์ในกลุ่มเรียงตามหมายเลขเครื่อง สามารถกดเลือกเครื่องที่ต้องการได้ หมุดกลุ่มใช้พิกัดจริงของเครื่องหมายเลขแรก ไม่เฉลี่ยพิกัดและไม่แยกหมุดเป็นแนวตั้งหรือเพิ่มความสูงแผนที่

## ผูกงานเดิมจากแผนที่โดยไม่เข้าหน้าบันทึก Patrol

Admin และช่างผู้ควบคุมงานเปิดรายละเอียดงาน Patrol จากหน้าผู้รับจ้างหรือหน้าช่างผู้ควบคุมงาน แล้วกด “ผูกมิเตอร์ที่มีอยู่กับเสานี้” ได้ ผู้รับจ้างดูและเลือกงานในกลุ่มได้ แต่แก้กลุ่มไม่ได้

เลือกงานเดิมด้วย PEA, CA หรือชื่อผู้ใช้ไฟ งานที่พิกัดตรงกันไม่ถูกเลือกอัตโนมัติ ระบบคงสมาชิกกลุ่มเดิมของเสาที่เลือกไว้ หากเลือกงานจากกลุ่มอื่น จะนำสมาชิกกลุ่มนั้นมาทั้งกลุ่มและขอยืนยัน สามารถเอากลุ่มที่เพิ่งเพิ่มออกก่อนบันทึกได้ รองรับรวมสูงสุด 8 งาน และปรับหมายเลขเครื่องได้โดยต้องไม่ซ้ำกัน

หลังยืนยัน API `linkPatrolPoleMembers` อัปเดตเฉพาะหมายเลขเครื่องใน DATA คอลัมน์ I และรหัสกลุ่มใน PatrolPoleGroups ไม่เพิ่มแถวงาน ไม่เปลี่ยนพิกัด PEA รูปถ่าย พัสดุ การส่งมอบ หรือผลตรวจ งานเก่าที่ไม่มีหมายเลขเครื่องสามารถกำหนดในหน้าต่างนี้ได้โดยไม่ต้องเปิดฟอร์ม Patrol

บันทึกประวัติคำขอในชีต PatrolPoleGroupEdits ซึ่งสร้างอัตโนมัติ ตรวจ snapshot กลุ่ม/เครื่องและสมาชิกทั้งกลุ่มภายใต้ Script Lock ปฏิเสธข้อมูลที่ถูกแก้ไขระหว่างเปิดหน้าต่าง และใช้ Request ID ป้องกันคำขอซ้ำ หากเขียนไม่สำเร็จจะพยายามคืนค่ากลุ่มและเครื่องเดิมก่อนแจ้งข้อผิดพลาด การส่งคำขอเก่าที่สำเร็จแล้วซ้ำไม่ย้อนทับการจัดกลุ่มใหม่ กลุ่มเดิมที่รวมไปแล้วจะไม่รับมิเตอร์ใหม่จากฟอร์มที่ยังค้างรหัสกลุ่มเก่าอยู่

## การตรวจสอบ

`test-inspector.cjs` ตรวจการเก็บกลุ่ม การข้ามหมายเลข การป้องกันซ้ำ การส่งคำขอซ้ำ การแก้ไข การผูกงานเก่า สิทธิ์ และการลบ ด้วย Google APIs จำลอง

`check-patrol-pole-groups.cjs` ตรวจใน Chromium ขนาดจอมือถือ: บันทึก 2 → 5 → 1 ใช้กลุ่มเดียวกัน คงข้อมูลเสา ล้างข้อมูลมิเตอร์/รูป/พัสดุ เปิดงานเดิมเมื่อเลือกเครื่องซ้ำ เรียงประวัติและรายงาน และเลือกงานจากหมุดในทั้งสองหน้า

`check-explicit-pole-markers.cjs` ตรวจกลุ่มเสาที่ผูกจริง หมุดเดี่ยวพิกัดเดียวกัน/ใกล้กัน การซูม การเปิดสลับกลุ่ม และการนำทางเดิม โดยแสดงกลุ่มหนึ่งเครื่องเป็นหมุดเดี่ยวเพื่อลดภาระการโหลดแผนที่

`check-existing-patrol-pole-link.cjs` ตรวจการเลือกงานเดิมจากแผนที่ การค้นหา รวม/เอากลุ่มออก เลขเครื่องซ้ำ หน้าจอเล็ก สถานะขณะบันทึก การลองใหม่ และสิทธิ์ผู้รับจ้าง

นำ Code.gs และ Index.html ไปแทนใน Apps Script แล้ว Deploy เวอร์ชันใหม่หนึ่งครั้ง ไม่ต้องสร้างชีตหรือแทรกคอลัมน์ด้วยตัวเอง


เฉพาะหน้าช่างผู้ควบคุมงานสำหรับ Admin/ช่างผู้ควบคุมงาน ลากหมุดเดี่ยวหรือหมุดกลุ่มเพื่อแก้พิกัดได้ทั้งมือถือและคอมพิวเตอร์ หน้าผู้รับจ้างไม่มีเครื่องมือแก้พิกัดและลากหมุดไม่ได้ แม้เปิดด้วยบัญชี Admin ฝั่งเซิร์ฟเวอร์ปฏิเสธบัญชีผู้รับจ้างที่เรียก API แก้พิกัดโดยตรงด้วย การลากเป็นตำแหน่งรอบันทึก ยังไม่เปลี่ยนพิกัดนำทาง กด “ตรวจพิกัดที่แก้ไขก่อนบันทึก” ดูค่าเดิม/ใหม่ แล้วกด “บันทึกพิกัด” เพื่อยืนยัน หรือ “ยกเลิกการแก้พิกัด” เพื่อคืนตำแหน่งเดิม การลากหมุดกลุ่มย้ายสมาชิกทั้งหมดที่ผูกกลุ่มเสานั้น รวมถึงสมาชิกที่ไม่อยู่ในตัวกรองปัจจุบัน ไม่ย้ายงานอื่นเพียงเพราะพิกัดตรงกัน

เซิร์ฟเวอร์ตรวจสิทธิ์งาน พิกัดเดิม และสมาชิกกลุ่มล่าสุดก่อนเขียนเฉพาะ Latitude/Longitude ใน DATA คอลัมน์ L/M พร้อมประวัติในชีต WorkCoordinateEdits ที่สร้างอัตโนมัติ รองรับบันทึกครั้งละ 100 งานและส่งคำขอเดิมซ้ำเมื่อเครือข่ายขัดข้อง หากงานหรือกลุ่มเปลี่ยนระหว่างลากจะไม่เขียนทับ ให้ยกเลิกแล้วโหลดข้อมูลล่าสุด ประวัตินี้ไม่เปลี่ยนหมายเลขเครื่อง กลุ่มเสา รูปถ่าย หรือผลตรวจ


หากลากแล้วตำแหน่งไม่ตรง ใช้หัวข้อ “กำหนดพิกัดเสาจาก LatLong” ที่แสดงอยู่เหนือแผนที่ในหน้าช่างผู้ควบคุมงาน เลือกงานจากดรอปดาวน์ “เลือกงาน / PEA ที่ต้องการแก้พิกัด” หรือกดหมุด แล้วกรอกช่อง “LatLong ของเสาที่เลือก” โดยช่องจะแสดงตั้งแต่เปิดหน้าและเปิดให้กรอกหลังเลือกงาน รองรับคู่พิกัดคั่นจุลภาคและข้อความ lat:/long: กด “กำหนดจุดจาก LatLong” เพื่อเลื่อนหมุดตัวอย่างและพาแผนที่ไปตำแหน่งนั้น โดยยังไม่เปลี่ยนพิกัดที่บันทึกไว้ จากนั้นตรวจตำแหน่งและกด “บันทึกพิกัด” ใช้กับ WBS และ Patrol และย้ายสมาชิกในกลุ่มเสาทั้งกลุ่มเหมือนการลาก พิกัดที่กรอกใช้ความละเอียดตามค่าที่ใส่ ไม่ปัดเหลือ 7 ตำแหน่งเหมือนการลาก
