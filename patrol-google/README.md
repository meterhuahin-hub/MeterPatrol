# เชื่อมฟอร์ม Patrol ที่ส่งมากับ Google Sheets

ชุดไฟล์นี้รักษาช่องสำรวจ WBS/TR/PEA พัสดุเก่า-ใหม่ GPS และรูปก่อน-หลังของฟอร์มที่ผู้ใช้ส่งมา ใช้แทน HTML แบบ standalone เดิม ห้ามเปิดไฟล์ Index.html แล้วคาดว่าจะบันทึกได้ ต้องเปิดผ่าน Apps Script deployment เท่านั้น

ชีตเป้าหมาย: https://docs.google.com/spreadsheets/d/1DydK1q8PZELyk2gTFmtxxiUtgSz6EYxRncw1Ep7JDSg/edit
ระบบสร้างแท็บ `PatrolSurvey` แยกจากข้อมูลเดิม ไม่เขียนทับแท็บ gid=0 หรือแท็บ MeterPatrol

## อัปเดตลิงก์เว็บเดิม
1. เปิดโปรเจกต์ Apps Script ที่เป็นเจ้าของ URL `/exec` เดิม (หากเปิดจาก Sheets แล้วเป็นคนละโปรเจกต์ ต้องเข้าโปรเจกต์ที่ deploy URL นั้น)
2. สำรองโค้ดเดิมก่อน จากนั้นแทน `Code.gs` และสร้าง/แทน HTML ชื่อ `Index` ด้วยไฟล์ในโฟลเดอร์นี้ หากมีไฟล์ .gs อื่นประกาศ doGet/listPatrol/savePatrol ซ้ำ ให้สำรองแล้วเอาฟังก์ชันซ้ำออก
3. เปิดการแสดง manifest ใน Project Settings แล้วแทน `appsscript.json` ด้วยไฟล์นี้
4. เพิ่ม Script property `ALLOWED_EMAILS` เป็นอีเมล Google ของเจ้าหน้าที่รวมผู้ดูแล คั่นด้วย comma
5. แชร์ Google Sheets เป้าหมายให้บัญชีเจ้าหน้าที่เป็น Editor ไม่มีรหัสผ่านที่ต้องกรอกหรือส่งในแชต
6. ถ้าใช้รูป: สร้างโฟลเดอร์ Google Drive แชร์ให้เจ้าหน้าที่เป็น Editor แล้วเพิ่ม `PHOTO_FOLDER_ID` ใน Script properties เป็น ID จาก URL โฟลเดอร์ รูปเก็บเป็นไฟล์ส่วนตัวในโฟลเดอร์นี้ ไม่แชร์สาธารณะ รูป JPEG ไม่เกินประมาณ 2 MB ต่อรูป ถ้าไม่ตั้งโฟลเดอร์ยังบันทึกงานที่ไม่แนบรูปได้
7. Deploy → Manage deployments → Edit → New version ตั้ง Execute as **User accessing the web app** และ Who has access **Anyone with Google account** (หรือเฉพาะองค์กร) แล้ว Deploy เพื่อรักษา URL เดิม Google อาจให้อนุญาตสิทธิ์ใหม่เพราะเพิ่ม Drive scope
8. เปิด URL `/exec` ไม่ใช่ HTML ที่ดาวน์โหลดไว้ เมื่ออ่านชีตสำเร็จ หน้าเว็บจะแสดง “โหลดข้อมูลจาก Google Sheets แล้ว” จึงเปิดให้บันทึก

ข้อสำคัญ: เจ้าหน้าที่ที่เป็น Editor อาจแก้ข้อมูล Sheets และ Apps Script ที่ผูกกับชีตได้ เหมาะกับทีมที่เชื่อถือกัน Google Workspace อาจจำกัด OAuth/การเผยแพร่ ผู้ดูแล Google ต้องแก้สิทธิ์ที่จำเป็น

## ทดสอบจริงหลัง deploy
กรอกวันที่, WBS หรือ TR, PEA `00001`, จำนวนพัสดุ แล้วบันทึก ตรวจข้อความ “Google Sheets ยืนยันการบันทึกแล้ว” และแถวใหม่ในแท็บ PatrolSurvey โหลดเว็บใหม่เพื่อยืนยันข้อมูลจากเซิร์ฟเวอร์ ทดสอบรูปและเปิดลิงก์ Drive ด้วยบัญชีเจ้าหน้าที่ ทดสอบบัญชีนอก allowlist ว่าเข้าไม่ได้

หน้าเว็บไม่ใช้ no-cors หรือ localStorage เพื่ออ้างว่าส่งสำเร็จอีกต่อไป การลบข้อมูลในชีตไม่ได้เปิดให้ทำจากฟอร์ม ภาพที่ส่งออกสำรองเป็นลิงก์ ไม่รวมไฟล์ภาพ GPS/กล้องใน iframe ของ Apps Script อาจถูกเบราว์เซอร์จำกัด โปรดทดสอบบนอุปกรณ์จริง ระบบยังอ่านประวัติทั้งหมดจึงเหมาะกับทีมขนาดเล็ก สำรอง Sheets/Drive เป็นระยะ

ไม่มีการย้ายข้อมูล localStorage เดิมอัตโนมัติ หากกรอกในฟอร์มเดิมให้ส่งออก JSON สำรองก่อน
