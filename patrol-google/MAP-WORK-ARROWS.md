# ลูกศรเลขงานในแผนที่สำรวจ

อัปเดต Code.gs และ Index.html ใน Apps Script แล้ว Deploy เป็นเวอร์ชันใหม่

1. เปิดเมนูแผนที่สำรวจ เลือกปี/WBS/TR แล้วเปิดชุดแผนที่
2. บันทึกภาพพร้อมกลุ่มและตัวอักษรเสาตามเดิม
3. ระบบจับคู่เสาอัตโนมัติจาก DATA คอลัมน์ E (TR) และ F (เสาที่) โดยจับตัวอักษร A–Z, AA… โดยตรง หรือเทียบเลขเสา 1=A, 2=B, 27=AA ไม่ใช้ลำดับแถวในชีต หากหลาย TR/กลุ่มใช้ตัวอักษรซ้ำ ให้ตั้งชื่อกลุ่มตรงกับ TR หรือเปิดชุดที่ระบุ TR เฉพาะ ระบบจะไม่เดาคู่ที่กำกวม ลูกศรใช้เสาที่ปัจจุบันในคอลัมน์ F โดยตรง การผูกเองที่บันทึกไว้เดิมไม่ใช้กำหนดปลายลูกศรแล้ว
4. งานที่ตรงกับ WBS/ปีของชุด และ TR/เสาที่ซึ่งผูกไว้ จะได้รับเลขงานอัตโนมัติ งานใหม่ใช้เลขถัดไป งานเดิมคงเลขเดิม แม้ปรากฏบนหลายภาพ
5. กดแสดงภาพ แล้วลากวงกลมเลขเพื่อหลบข้อความ ตำแหน่งเก็บไว้ในหน้าเว็บก่อน ไม่ส่งบันทึกทุกครั้งที่ลาก กด “ย้อนกลับ” เพื่อยกเลิกการลากล่าสุด (ย้อนหลายขั้นได้ในช่วงที่เปิดชุดนี้ รวมถึงหลังบันทึก โดยต้องกดบันทึกอีกครั้งเพื่อยืนยันผลย้อนกลับ) แล้วกด “บันทึกตำแหน่งลูกศร” เพื่อส่งทุกตำแหน่งพร้อมกัน ตำแหน่งแยกแต่ละภาพ หากบันทึกล้มเหลว ข้อมูลที่จัดยังอยู่ให้ลองใหม่ ก่อนเปลี่ยนชุด/โหลดใหม่มีการเตือนหากมีตำแหน่งค้าง และเบราว์เซอร์จะเตือนก่อนปิด/รีเฟรชหน้า
6. กดแสดงทุกภาพก่อนพิมพ์ / PDF แล้วพิมพ์ ลูกศรและตารางอ้างอิงจะอยู่ในเอกสารด้วย

แก้ไขการผูกเสาและย้ายวงกลมได้เฉพาะ Admin/ช่างผู้ควบคุมงาน เลขที่เคยใช้จะไม่ถูกนำกลับมาใช้ซ้ำเมื่อมีงานถูกลบ จึงอาจมีเลขข้ามได้ ชุดที่เลือกปีหรือ TR ต่างกันถือเป็นคนละชุดและมีลำดับเลขแยกกัน

ระบบเพิ่มแท็บ MapPoleBindings, MapWorkNumbers และ MapArrowPositions อัตโนมัติ ไม่ต้องเพิ่มคอลัมน์ใน DATA

ตรวจด้วยแบบจำลอง Google APIs และทดสอบตรรกะตำแหน่งภาพแล้ว ยังต้องตรวจภาพจริงและการพิมพ์หลัง Deploy ใน Apps Script

การย้อนกลับในแถบลูกศรครอบคลุมการลากตำแหน่งวงกลม ส่วนตัวอักษรเสาที่ยังไม่บันทึกภาพใช้ปุ่ม “ลบเสาล่าสุดในกลุ่ม” ตามเดิม ไม่ใช่การย้อนประวัติการแก้ไขข้อมูล DATA หรือการผูกเสาเอง

ตารางอ้างอิงแสดงเฉพาะ ลำดับ, TR, เสาที่, PEA และประเภทงาน โดยเอาคอลัมน์ “กลุ่ม / รหัสเสา” ออก ตัวอักษรบนแผนที่ยังใช้เป็นตำแหน่งของเสา (เช่น เสาที่ 3 ชี้ C)

## ข้อความบนภาพ

กดแสดงภาพที่ต้องการ ในส่วน “ข้อความบนแผนที่” พิมพ์ข้อความ เลือกสี/ขนาด แล้วกด “เพิ่มข้อความ” และคลิกบนภาพเพื่อวาง คลิกข้อความที่มีอยู่เพื่อเลือก แล้วแก้ช่องข้อความ/สี/ขนาดและกด “ใช้ข้อความ / รูปแบบที่แก้ไข” ลากเพื่อย้าย ใช้ปุ่มลบหรือย้อนกลับข้อความได้ จากนั้นกด “บันทึกข้อความ” เพื่อบันทึกทุกภาพที่แก้พร้อมกัน

ข้อความเก็บแยกในแท็บ MapTextAnnotations ซึ่งสร้างอัตโนมัติ ไม่แก้ไฟล์รูปต้นฉบับ ข้อความปรากฏในภาพและตอนพิมพ์/PDF ย้อนกลับได้หลายขั้นในชุดที่เปิดอยู่ รวมถึงหลังบันทึก (ต้องบันทึกผลย้อนกลับอีกครั้ง) ผู้รับจ้างที่มีสิทธิ์เข้าถึงชุดแผนที่เห็นข้อความได้ แต่แก้ไขได้เฉพาะ Admin/ช่างผู้ควบคุมงาน

รองรับ 200 ข้อความต่อภาพ ข้อความละไม่เกิน 1,000 ตัวอักษร / 20 บรรทัด และข้อมูลข้อความรวมต่อภาพไม่เกิน 45,000 ตัวอักษร เพื่อให้เก็บในเซลล์ Google Sheets ได้ การพิมพ์ใช้ตำแหน่งและขนาดตามภาพจริง

ตรวจการวาง แก้ไข ลาก ลบ ย้อนกลับ บันทึก เปิดกลับ และการมองเห็นในโหมดพิมพ์ด้วย Chromium ผ่าน check-map-text-browser.cjs (API จำลอง) และตรวจการเก็บข้อมูล/สิทธิ์/การชนกันของเวอร์ชันด้วย test-inspector.cjs ยังไม่ได้ทดสอบกับ Apps Script ที่ Deploy จริง
