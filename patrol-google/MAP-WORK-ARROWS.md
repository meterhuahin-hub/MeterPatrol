# ลูกศรเลขงานในแผนที่สำรวจ

อัปเดต Code.gs และ Index.html ใน Apps Script แล้ว Deploy เป็นเวอร์ชันใหม่

1. เปิดเมนูแผนที่สำรวจ เลือกปี/WBS/TR แล้วเปิดชุดแผนที่
2. บันทึกภาพพร้อมกลุ่มและตัวอักษรเสาตามเดิม
3. ระบบจับคู่เสาอัตโนมัติจาก DATA คอลัมน์ E (TR) และ F (เสาที่) โดยจับตัวอักษร A–Z, AA… โดยตรง หรือเทียบเลขเสา 1=A, 2=B, 27=AA ไม่ใช้ลำดับแถวในชีต หากหลาย TR/กลุ่มใช้ตัวอักษรซ้ำ ให้ตั้งชื่อกลุ่มตรงกับ TR หรือเปิดชุดที่ระบุ TR เฉพาะ ระบบจะไม่เดาคู่ที่กำกวม ลูกศรใช้เสาที่ปัจจุบันในคอลัมน์ F โดยตรง การผูกเองที่บันทึกไว้เดิมไม่ใช้กำหนดปลายลูกศรแล้ว
4. งานที่ตรงกับ WBS/ปีของชุด และ TR/เสาที่ซึ่งผูกไว้ จะได้รับเลขงานอัตโนมัติ งานใหม่ใช้เลขถัดไป งานเดิมคงเลขเดิม แม้ปรากฏบนหลายภาพ
5. กดแสดงภาพ แล้วลากวงกลมเลขเพื่อหลบข้อความ ตำแหน่งเก็บไว้ในหน้าเว็บก่อน ไม่ส่งบันทึกทุกครั้งที่ลาก กด “ย้อนกลับ” เพื่อยกเลิกการลากล่าสุด (ย้อนหลายขั้นได้ในช่วงที่เปิดชุดนี้ รวมถึงหลังบันทึก โดยต้องกดบันทึกอีกครั้งเพื่อยืนยันผลย้อนกลับ) แล้วกด “บันทึกตำแหน่งลูกศร” เพื่อส่งทุกตำแหน่งพร้อมกัน ตำแหน่งแยกแต่ละภาพ หากบันทึกล้มเหลว ข้อมูลที่จัดยังอยู่ให้ลองใหม่ ก่อนเปลี่ยนชุด/โหลดใหม่มีการเตือนหากมีตำแหน่งค้าง และเบราว์เซอร์จะเตือนก่อนปิด/รีเฟรชหน้า
6. กดแสดงทุกภาพก่อนพิมพ์ / PDF แล้วพิมพ์ ลูกศรและตารางอ้างอิงจะอยู่ในเอกสารด้วย

แก้ไขการผูกเสาและย้ายวงกลมได้เฉพาะ Admin/ช่างผู้ควบคุมงาน เลขที่เคยใช้จะไม่ถูกนำกลับมาใช้ซ้ำเมื่อมีงานถูกลบ จึงอาจมีเลขข้ามได้ ชุดที่เลือกปีหรือ TR ต่างกันถือเป็นคนละชุดและมีลำดับเลขแยกกัน

ระบบเพิ่มแท็บ MapPoleBindings, MapWorkNumbers และ MapArrowPositions อัตโนมัติ ไม่ต้องเพิ่มคอลัมน์ใน DATA

ตรวจด้วยแบบจำลอง Google APIs และทดสอบตรรกะตำแหน่งภาพแล้ว ยังต้องตรวจภาพจริงและการพิมพ์หลัง Deploy ใน Apps Script

การย้อนกลับในแถบลูกศรครอบคลุมการลากตำแหน่งวงกลม ส่วนตัวอักษรเสาที่ยังไม่บันทึกภาพใช้ปุ่ม “ลบเสาล่าสุดในกลุ่ม” ตามเดิม ไม่ใช่การย้อนประวัติการแก้ไขข้อมูล DATA หรือการผูกเสาเอง

ตารางอ้างอิงแสดงเฉพาะ ลำดับ, TR, เสาที่, PEA และประเภทงาน โดยเอาคอลัมน์ “กลุ่ม / รหัสเสา” ออก ตัวอักษรบนแผนที่ยังใช้เป็นตำแหน่งของเสา (เช่น เสาที่ 3 ชี้ C)

## ข้อความบนภาพ

กดแสดงภาพที่ต้องการ ในส่วน “ข้อความบนแผนที่” พิมพ์ข้อความ เลือกสี/ขนาด แล้วกด “เพิ่มข้อความ” และคลิกบนภาพเพื่อวาง คลิกข้อความที่มีอยู่เพื่อเลือก แล้วแก้ช่องข้อความ/สี/ขนาดและกด “ใช้ข้อความ / รูปแบบที่แก้ไข” ลากเพื่อย้าย ใช้ปุ่มลบหรือย้อนกลับข้อความได้ จากนั้นกด “บันทึกข้อความ” เพื่อบันทึกทุกภาพที่แก้พร้อมกัน

ข้อความเก็บแยกในแท็บ MapTextAnnotations ซึ่งสร้างอัตโนมัติ ไม่แก้ไฟล์รูปต้นฉบับ ข้อความปรากฏในภาพและตอนพิมพ์/PDF ย้อนกลับได้หลายขั้นในชุดที่เปิดอยู่ รวมถึงหลังบันทึก (ต้องบันทึกผลย้อนกลับอีกครั้ง) ผู้รับจ้างที่มีสิทธิ์เข้าถึงชุดแผนที่เห็นข้อความได้ แต่แก้ไขได้เฉพาะ Admin/ช่างผู้ควบคุมงาน

รองรับ 200 ข้อความต่อภาพ ข้อความละไม่เกิน 1,000 ตัวอักษร / 20 บรรทัด และข้อมูลข้อความรวมต่อภาพไม่เกิน 45,000 ตัวอักษร เพื่อให้เก็บในเซลล์ Google Sheets ได้ การพิมพ์ใช้ตำแหน่งและขนาดตามภาพจริง

ตรวจการวาง แก้ไข ลาก ลบ ย้อนกลับ บันทึก เปิดกลับ และการมองเห็นในโหมดพิมพ์ด้วย Chromium ผ่าน check-map-text-browser.cjs (API จำลอง) และตรวจการเก็บข้อมูล/สิทธิ์/การชนกันของเวอร์ชันด้วย test-inspector.cjs ยังไม่ได้ทดสอบกับ Apps Script ที่ Deploy จริง

## หมุนข้อความและซูมตอนแก้ไข

เลือกข้อความบนภาพ ใส่องศาในช่อง “หมุน (องศา)” (ตั้งแต่ -360 ถึง 360) แล้วกด “ใช้ข้อความ / รูปแบบที่แก้ไข” และ “บันทึกข้อความ” ข้อความเดิมที่ยังไม่เคยหมุนเริ่มที่ 0 องศา รองรับย้อนกลับการเปลี่ยนองศาและลากข้อความที่หมุนแล้วได้

ภาพที่บันทึกแล้วมีปุ่มซูมเข้า/ออก/พอดีภาพ และหมุนล้อเมาส์เพื่อซูมตรงจุดที่ชี้ได้ 1–8 เท่า กด Alt หรือปุ่มกลางเมาส์ค้างแล้วลากเพื่อเลื่อนภาพ (หรือใช้แถบเลื่อน) ซูมแต่ละภาพแยกกัน ตำแหน่งข้อความและลูกศรเก็บเป็นสัดส่วนภาพเดิม ไม่เปลี่ยนตามระดับซูม ตอนพิมพ์/PDF จะแสดงภาพเต็มตามขนาดหน้า พร้อมองศาที่บันทึกไว้

เสาที่ใน DATA คอลัมน์ F “เมนA”, “เมน B”, “เมนAA” และ “MAIN C” ชี้จุดเมนA, เมนB, เมนAA, เมนC ตามลำดับ ซึ่งเป็นคนละจุดกับ A, B, AA, C ในส่วนกำหนดเสาบนภาพ ให้เลือก “ชุดรหัสเสา” เป็น “เมนA, เมนB, เมนC…” แล้วคลิกตำแหน่งเสาเมนจริง ลำดับเมนเริ่ม A แยกจากเสาปกติและต่อข้ามภาพได้ ถ้าไม่มีจุดเมนบนภาพจะไม่ใช้เสาปกติแทน ยังคงใช้ TR และปี/WBS เพื่อเลือกกลุ่ม และไม่เปลี่ยนชื่อเสาใน DATA

งานที่ยังไม่มีจุดตรงกันจะแสดงในตารางด้วย พร้อมสถานะยังไม่พบจุด สำหรับงานเสาเมนสามารถกด “กำหนดจุด เมนA” แล้วคลิกตำแหน่งจริงบนภาพที่บันทึกไว้ได้โดยไม่ต้องอัปโหลดใหม่ จุดเก็บใน MapMainPoints แยกจากรูปต้นฉบับและเสา A ใช้ Escape เพื่อยกเลิกโหมดวางจุด การวางจุดทำได้เฉพาะผู้ดูแล/ผู้ควบคุมงาน และไม่เขียนทับจุดที่มีอยู่แล้วด้วยตำแหน่งต่างกัน

## แผนที่ในหน้าบันทึกงาน WBS

เลือกปีงบประมาณ พ.ศ., WBS, TR แล้วกด “เปิดแผนที่สำรวจ / เลือกเสา” ระบบเลือกชุดแผนที่ตรงกันก่อน และรองรับชุดที่สร้างแบบทุกปี/ทุก TR หากมีหลายชุดเลือกสลับได้ในหน้าต่าง เลือกภาพ ซูม/เลื่อน แล้วแตะรหัสเสาเพื่อดูจำนวนงาน/PEA และกด “ใช้เสานี้ / กลับไปบันทึก” เพื่อเติมเสาที่ โดย A กับเมนA เป็นคนละจุด ถ้ากำลังแก้ไขงานเก่า ระบบถามก่อนเปลี่ยนเสาที่

สีเขียว ✓ หมายถึงมีงานสำรวจบันทึกสำเร็จแล้ว ไม่ใช่สถานะตรวจรับงาน คำนวณจาก DATA ตามปีงบประมาณ + WBS + TR + เสาที่ และสิทธิ์ดูงาน ถ้างานสุดท้ายของเสาถูกลบ จุดนั้นกลับเป็นยังไม่สำรวจเมื่อเปิด/โหลดสถานะล่าสุด ทั้งหน้าแผนที่สำรวจและหน้าต่างในแบบฟอร์มใช้ข้อมูลจริงเดียวกัน เครื่องหมายแสดงตอนพิมพ์ด้วย แตะเครื่องหมายในหน้าแผนที่เพื่อดูจำนวนงาน/PEA ได้

จำภาพ/ตำแหน่งเลื่อน/ระดับซูมล่าสุดระหว่างใช้งาน (ล้างเมื่อออกจากระบบ) หลังบันทึกจากแผนที่สำเร็จจะคงปี/WBS/TR ไว้สำหรับเสาถัดไป โหลดภาพจากแคชในหน่วยความจำ แต่สถานะงานจะโหลดใหม่เมื่อเปิดแผนที่ หากไม่มีพิกัดจุดเสาในข้อมูลแผนที่ หรือรหัสซ้ำหลายกลุ่มจนระบุ TR ไม่ได้ ระบบไม่เดาจุดให้ และแจ้งให้ตรวจกลุ่มเสาแทน

ทดสอบหน้าต่างแบบเต็มจอ การเลือก A/เมนA การดูงาน และการจำซูมด้วย Chromium ผ่าน check-field-survey-map.cjs (API จำลอง) และทดสอบการแยกปี/สิทธิ์/งานถูกลบด้วย test-inspector.cjs

## การโหลดหน้าเว็บ

Code.gs ส่งหน้าเริ่มต้นขนาดเล็กเพื่อแสดงสถานะโหลด จากนั้น getAppDocument ตรวจสิทธิ์บัญชี Google และส่งต้นฉบับ Index/Leaflet ผ่าน RPC ให้แสดงใน iframe srcdoc ที่ใช้ Google RPC bridge ของหน้าเริ่มต้น จึงไม่ส่ง JavaScript ทั้งแอปผ่านตัวประมวลผล HTML ของ HtmlService ตั้งแต่คำขอแรก หาก RPC ล้มเหลวจะมีข้อความและปุ่มลองใหม่ ไม่ปล่อยหน้าว่าง หน้าเริ่มต้นไม่ต้องใช้ DI token เพราะส่งเฉพาะโค้ดหน้า Login; API ข้อมูลงานยังตรวจสิทธิ์ตามเดิม

ตรวจตัวโหลด การเข้าสู่ระบบใน iframe การส่งต่อ Google RPC และข้อผิดพลาดโหลดด้วย check-app-bootstrap.cjs (Chromium และ Google API จำลอง) ยังต้องยืนยันกับ deployment จริง

## สถานะเสาบนมือถือ

เสาที่ยังไม่สำรวจแสดงสีเดิม แตะเลือกเป็นสีม่วงเข้ม (งานที่บันทึกแล้วเมื่อเลือกเป็นเขียวเข้มพร้อม ✓) สีที่เลือกเป็นสถานะขณะใช้งาน ไม่เขียนลงชีตและไม่ทำให้เป็นสำรวจแล้ว เมื่อบันทึกสำเร็จจะใช้ข้อมูลจริงเป็นสีเขียว ✓ ทั้งสองหน้า; ลบงานสุดท้ายแล้วจะกลับเป็นยังไม่สำรวจเมื่อเปิด/โหลดสถานะใหม่

เพิ่มพื้นที่รับการแตะอย่างน้อย 44 CSS พิกเซล และปรับตามระดับซูม โดยตำแหน่งจริงไม่เปลี่ยน หน้าแผนที่สำรวจแตะได้ทั้งเสาที่ยังไม่สำรวจและเสาที่สำรวจแล้ว รายละเอียดแสดงใต้ส่วนควบคุม ส่วนหน้าต่างแผนที่ในแบบฟอร์มมีรายการเลือกเสาสำรองสำหรับจุดที่อยู่ชิดกัน A และเมนA ยังแยกกัน เมื่อออกจากระบบจะล้างสถานะการเลือก

ตรวจด้วย Chromium ทั้งหน้าจอ desktop และ mobile emulation ของ Pixel 5/iPhone 13 ผ่าน check-field-survey-map.cjs ไม่ใช่การทดสอบบนเครื่อง Android หรือ Safari จริง
