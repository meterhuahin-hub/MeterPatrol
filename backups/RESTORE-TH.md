## กู้คืนเว็บ Google Apps Script

1. แตกไฟล์ ZIP แล้วเปิดโฟลเดอร์ `MeterPatrol/patrol-google`
2. ในโครงการ Apps Script เดิม แทนไฟล์ `Index.html`, `Code.gs` และตรวจไฟล์ HTML ประกอบตาม README ของโฟลเดอร์ อย่านำไฟล์ของ `apps-script/` ซึ่งเป็นอีกเวอร์ชันมาปนกัน
3. ใช้ Google Sheets และโฟลเดอร์รูปเดิม ตรวจ Script properties เช่น `ALLOWED_EMAILS`, `PHOTO_FOLDER_ID` และการตั้งค่าอื่นในโครงการเดิม สำเนานี้ไม่มีค่าจริงของ Script properties
4. ตรวจสิทธิ์เข้าถึงชีต/โฟลเดอร์ แล้วอัปเดต deployment เดิมตาม README เพื่อคง URL ที่ APK ใช้
5. ทดสอบเข้าสู่ระบบ โหลดงาน และงานตัวอย่างหนึ่งรายการด้วยบัญชีของตนก่อนใช้งานต่อ

## APK และกุญแจเซ็น

ติดตั้ง APK ล่าสุดได้จาก `android/releases/MeterPatrol-1.3.0.apk` การอัปเดตเว็บที่ URL เดิมไม่จำเป็นต้องสร้าง APK ใหม่

หากต้องสร้าง APK เวอร์ชันใหม่เพื่อติดตั้งทับเดิม ต้องเก็บไฟล์ส่วนตัว `MeterPatrol-Android-signing-PRIVATE-2026-11-21.zip` ด้วย ZIP นี้มีทั้งกุญแจเซ็นและรหัสผ่าน ไม่รวมใน GitHub หรือ ZIP โปรแกรม ห้ามส่งต่อหรืออัปโหลดสาธารณะ ไฟล์ ZIP ส่วนตัวนี้ไม่ได้เข้ารหัสเพิ่ม

แตก ZIP ส่วนตัว แล้วใช้โฟลเดอร์ `Android-signing` กับตัวเลือก `--signing-dir` ตาม `android/README.md` ห้ามสร้างกุญแจใหม่ทับหากยังต้องการอัปเดตแอปเดิม
